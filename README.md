# XPlay eBooks

Original ebooks published by MR SAQLAIN PRODUCTIONS for the XPlay store. No author names are credited; publisher only.

Each book is over 50 pages (PDF, A4, 14pt readable layout; manuscript pages at 250 words/page also over 50). Formats per book: EPUB, PDF, HTML, TXT — plus a zip with all formats and the cover.

MOBI/AZW3 are not provided (no KindleGen/Calibre in the build environment); EPUB converts losslessly to MOBI in Calibre.
